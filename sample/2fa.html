💡 網址 URL 參數說明：

  1. macOS 本地開啟 (Query 參數，不被 macOS open 指令截斷)：
    open 'file:///Users/hungte/Downloads/2fa.html?secret=JBSWY3DPEHPK3PXP&account=abc'
  2. HTTP 伺服器最安全方式 (URL Hash 錨點，Proxy 絕不留 Log)：
    http://your-server/2fa.html#secret=JBSWY3DPEHPK3PXP&account=abc
🔒 資安保護機制：頁面設有 Cache-Control: no-store 禁止 Proxy 快取。在 HTTP 伺服器環境下，使用 Query 參數 (?secret=...) 會自動清理網址列防洩漏；本地檔 (file://) 則不會自動清理以方便測試與刷新。
